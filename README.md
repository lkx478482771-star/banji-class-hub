# 班集 · 班级共建站

一个面向大学生的班级服务网页，覆盖互助信息、任务组队、共享资料、截止提醒、匿名意见和竞选承诺展示。

## 账号与登录

- 用户只需要输入账号名称和密码，不需要填写邮箱。
- 网站不请求 Supabase，账号和班级内容使用不需要注册的 MantleDB 公共存储接口。
- 账号名称在班级共享数据库中不能重复。
- 用户可以修改自己的展示昵称；昵称仅限 2 到 8 个汉字，每个自然日最多修改一次。
- 密码使用 Web Crypto PBKDF2 加盐后保存，网站不会保存明文密码。
- 登录会话保存在当前浏览器中，刷新或重新打开网站后会自动识别；只有主动退出登录后才需要重新输入。
- 不同账号在同一浏览器中使用独立的数据空间。

## 身份系统

网站支持多班级。用户注册时凭班级邀请码加入，也可以在登录后继续加入其它班级并随时切换。每个班级独立保存成员、互助、组队、资料、截止事项和匿名意见。

注册和编辑资料时可以设置当前班级内的身份，成员目录会按照“教师与辅导员、班级委员会、普通同学”分组展示：

- 教师与辅导员：任课老师、班主任、辅导员。
- 班级委员会：班长、副班长、团支书、学习、生活、体育、文艺、心理、宣传、组织、纪律和劳动委员。
- 普通同学：默认身份。

教师和班委身份需要当前班级管理员或站点管理员审核。普通用户提交申请后仍保持普通同学权限，只有审核通过后身份才会生效。

当前班级管理员包括班长、副班长、辅导员和班主任，只能管理本班成员与内容。站点管理员账号为“刘凯翔”，可以创建、停用和进入全部班级，并审核任意班级的身份申请。

系统首次使用时会自动创建“默认班级”，邀请码为 `BANJI-2026`。站点管理员可在“班级管理”中创建正式班级并设置独立邀请码。

界面会根据当前班级身份分组呈现不同风格：

- 普通同学使用基础班级服务界面。
- 班委使用蓝色工作台主题，并显示任务、日程和成员入口。
- 教师与辅导员使用暖色工作台主题。
- 管理员使用红色管理主题，并显示班级管理、身份审核与历史记录入口。

竞选栏目只对 `config.js` 中 `campaignUsernames` 指定的作品作者开放。当前仅“刘凯翔”账号可以进入竞选页，其他用户即使手动输入地址也会被重定向到个人中心。

## 发布额度与管理员

- 每个账号每天最多发布 10 条，互助、组队、意见和截止事项均包含在内。
- 同一类型每天最多发布 5 条，额度记录在共享数据库中，清理浏览器无法绕过。
- 用户可以在“个人中心”查看自己的身份、发布记录与今日剩余额度。
- 用户只能删除自己发布的内容。
- 配置文件中的管理员账号拥有全站权限，包括创建与管理全部班级、身份审核、任务与日程发布、删除任意内容和删除历史记录。当前管理员账号为“刘凯翔”。

## 事项保留与历史记录

- 任务、组队和日程由班委、教师、辅导员或管理员发布，普通同学没有发布权限。
- 发布者可以选择保留 `6、12、24、48` 小时，最长不超过 48 小时。
- 到期后事项自动从当前栏目移除，并归档到“历史记录”页面。
- 管理员可以从历史记录中永久删除归档内容。

## 本地预览

在网站根目录运行：

```powershell
python -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。

## 数据模式

当前版本使用轻量共享模式：

- 注册、同名校验、互助、组队、意见和截止事项通过 MantleDB 在设备之间同步。
- 登录会话和上传文件保存在当前浏览器中，上传文件不会发送到共享接口。
- MantleDB 是无账号公共原型服务，不应存放密码明文、身份证号等敏感信息。
- 长期稳定运营或处理班级隐私数据时，建议迁移到腾讯云、阿里云或已备案的国内服务。

## 部署

整个目录可直接上传到 GitHub Pages、Netlify、Vercel 或普通静态服务器。入口文件是 `index.html`，所有运行资源均使用相对路径。

## 数据说明

- 上传文件保存在当前浏览器的 IndexedDB 中。
- 候选人资料、匿名意见和所有班级内容保存在浏览器本地。
- 账号密码只保存加盐摘要，不保存明文。
