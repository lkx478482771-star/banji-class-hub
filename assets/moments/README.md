# 美好片刻 · 照片怎么往里放

运动会当天的照片放在这个目录里，班集站点的「IC-4 运动会」栏目会自动显示。

## 步骤

1. **传照片**：把照片拷进 `assets/moments/` 目录（就是本目录）。
   - 建议先压一下：单张控制在 300KB 以内，长边 1600px 就够手机看了。
   - 文件名用英文或拼音，不要用空格和特殊符号，例如 `qipao-01.jpg`、`jieli-02.jpg`。
2. **登记**：打开同目录的 `manifest.json`，在 `photos` 数组里按下面的格式加一行。

```json
{
  "updated": "2026-10-18",
  "photos": [
    { "file": "qipao-01.jpg", "title": "女子 100 米起跑" },
    { "file": "jieli-02.jpg", "title": "4×100 米接力交接", "date": "2026.10.18 上午" }
  ]
}
```

3. **提交上线**：提交并推送到 GitHub，等 1–2 分钟 GitHub Pages 自动更新。

## 字段说明

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `file` | 是 | 文件名，要和本目录里的实际文件名完全一致（区分大小写） |
| `title` | 否 | 显示在图下面的标题，缺省是「美好片刻」 |
| `date` | 否 | 显示在图下面的小字，缺省是「2026.10.18 · 安徽大学 龙河校区」 |

## 注意

- `photos` 是空数组时，页面会显示 8 张占位卡（开幕式 / 起跑 / 冲线 / 接力 / 跳跃 / 加油瞬间 / 颁奖 / 班级合影），这也是正常的。
- 照片没登记进 `manifest.json` 就不会显示。
- 这个目录在 `assets/` 的子目录里，不参与仓库的首屏体积门禁（门禁只统计 `assets/` 的直接子项）。
- 上传前请确认照片里同学的肖像使用已经打过招呼，避免不必要的麻烦。
