# 班集 · 班级共建站

一个面向大学生的班级服务网页，覆盖互助信息、任务组队、共享资料、截止提醒、匿名意见和竞选承诺展示。

## 本地预览

在 `outputs` 目录运行：

```powershell
python -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。

## 开启班级云同步

网站复用了已有 Supabase 项目，但使用独立的 `class_hub_records` 表，不会影响中秋祝福数据。

首次使用前，在 Supabase Dashboard 的 SQL Editor 中执行：

```text
supabase/migrations/202609270001_class_hub_records.sql
```

执行后会创建班级共享记录表并启用 RLS：

- 所有访客都能读取公开内容。
- 匿名访客可以发布互助、组队、意见和截止事项。
- 单浏览器十分钟最多发布 30 条，数据库与前端均有基础限流。
- 隐藏内容或删除记录可在 Supabase Dashboard 中处理。

未执行迁移或网络不可用时，网站会自动切换到本地模式，所有现有功能仍可演示；发布内容会保留在当前浏览器，并在恢复连接后自动重试同步。

## 部署

整个目录可直接上传到 GitHub Pages、Netlify、Vercel 或普通静态服务器。入口文件是 `index.html`，所有运行资源均使用相对路径。

## 数据说明

- `class_hub_records` 只存储互助、组队、匿名意见和截止事项的文本数据。
- 上传文件保存在当前浏览器的 IndexedDB 中，不会上传到 Supabase。
- 候选人资料和匿名意见的处理状态保存在浏览器本地；公开意见正文会同步到班级云。
