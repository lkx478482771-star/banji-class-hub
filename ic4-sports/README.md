# IC-4 运动会页（不用登录）

集成电路 4 班运动会页：出战名单 + 晶圆图 + 倒计时 + **匿名加油墙** + **赛场原声**。
**打开就能看，不用登录、不用注册**；加油写完立刻上墙，不需要审核。

线上地址：https://lkx478482771-star.github.io/banji-class-hub/ic4-sports/
管理页（只有负责人用）：同目录下的 `admin.html`，默认口令 `ic4-2026`（只用来看和下架）

## 页面上有什么

- 晶圆图：31 颗芯片 = 31 位选手，点一颗看他的出战参数
- 径赛 / 田赛筛选、出战名单、应援语
- 距开赛倒计时、一键通电 / 复位动画
- 加油墙：匿名写，写完**立刻**出现在墙上；负责人只在 `admin.html` 里看和删。
  两条自动规矩：**一模一样的话不会重复上墙**（页面上当面拦一次，已经存在的老重复留言在读取时自动清掉），
  而且**同一位同学、同一台设备最多加 2 次油**
- 赛场原声：直接播旧站 `assets/music/` 里那三首（不复制第二份）
- 首屏顶部就有「写一句加油 / 看加油墙」两个入口，手机上不用先滚过整张晶圆图

**没有**：登录、账号、密码、照片上传、成绩录入。

## 加油墙是怎么放数据的

- 复用旧站同一个 Supabase 项目，但写在**自己的专用分区**里：
  `banji-ic4-cheer-live`（墙上显示的全部内容）
- 旧站的代码只认它自己那批 `banji-ahu-*` 分区，所以这些留言不会跑到旧网站上
- **不需要跑任何 SQL**，也不需要新建表
- 代价要讲清楚：机器上没有任何把关——知道接口地址的人能删掉这个分区里的留言。
  想要服务端限频/收权限，就跑可选的 `supabase/ic4-cheers.sql`（把读写搬到服务端函数里），
  不跑也能正常用。

### 两条自动规矩（防刷屏）

1. **完全重复的留言自动清理**：同一个对象（`IC4-0xx` 或 `ALL`）+ 同一段文字（去空白、忽略大小写）
   只留最早的那条，其余在**读回来的时候**删掉（`cheer-api.js` 的 `pruneDuplicates()`）。
   限流：单次最多清 30 条、两次清理至少隔 20 秒；清理失败（权限/网络）只当没清，绝不影响读留言。
   页面上会写一句「已自动清理 N 条完全重复的留言」。
   注意：删帖这件事仍然只发生在 `cheer-api.js` 里，公开页（`app.js`）只提交和读——
   `tools/smoke.mjs` 会把这条当红线检查（`app.js` 里出现 `.discard(` 就算失败）。
2. **同一位同学最多 2 次**：每台设备有一个本地编号（`localStorage` 的 `ic4-cheer-dev-v1`，
   形如 `d-xxxxxx`），写上去的每条留言都带这个编号，页面按它数「你已经给这位同学加过几次油」。
   数到 2 就拦下来（墙上已有的 + 本机还没传上去的一起算）。
   这是**防刷屏**、不是防作弊：清掉浏览器数据或换台设备就重新算；留言本身仍然是匿名的，
   页面上不会显示、也不会拿这个编号认人。

## 连不上网也不会「报错」

同学的网络（尤其手机）经常连不上 Supabase —— 本机实测就是**直连该域名 TLS 一握手就被掐断**
（TCP 能连上、证书阶段就断，curl 直连 `http=000`，走代理 `http=401` 正常）。
所以这一页照抄「中秋节」那页的思路，把「连不上」做成可以接受的状态：

- 读不到线上数据 → **不显示错误**，用上次同步到的（浏览器缓存）+ 页面里带的静态快照顶着，
  再配一句「网络有点慢，先显示上次同步到的加油。」和一个「再试一次」按钮；
  自动重试是**由密到疏**的（8 秒 → 20 秒 → 45 秒 → 1 分钟，最多 8 次），之后停下来等
  「再试一次」或者手机重新有网（`online` 事件），免得一直空打网络费电
- 写加油时网络不通 → **不丢内容**：先存在这台设备的 `localStorage`（键名以 `ic4-cheer-` 开头），
  页面上显示「还有 N 句存在这台设备上」，网络一通就自动传上去
- 静态快照 = `cheers-seed.json`，构建时由 `tools/build.mjs` 打进 `data.js` 的 `window.IC4_CHEERS`。
  更新快照（需要走本机代理）：

```
cd ic4-sports
$env:NODE_USE_ENV_PROXY="1"; $env:HTTPS_PROXY="http://127.0.0.1:7897"
node tools/sync-cheers.mjs --show   # 把线上「已上墙」的留言抓下来，写进 cheers-seed.json
node tools/build.mjs                # 把快照打进 data.js
```

## 墙太长 / 想删掉某一条

数据库对每个分区有 4000 条上限，满了新的就写不进去。平时不用管；条数多了（`node tools/cloud-check.mjs list`
看条数）跑一次清理，只留最新的：

```
cd ic4-sports
$env:NODE_USE_ENV_PROXY="1"; $env:HTTPS_PROXY="http://127.0.0.1:7897"
node tools/cloud-check.mjs prune 300   # 只留最新 300 条，更老的删掉
```

删某一条不合适的留言：打开线上 `admin.html`，输入口令，点那一条的「下架」。

## 怎么加表外补报的选手

主名单来自 `运动会宣传/运动员名单.csv`（31 人）。后来才报名的人写进 `extra-athletes.json`
（就在这个目录里），**只加在这一页上，旧站一个字都不用改**：

```json
[
  { "name": "曹可瑞", "group": "女子组", "events": ["女子 200 米"], "cheer": "女子 200 米，一路通电到底。" }
]
```

- 项目名要和 CSV 里写得一样（「女子 200 米」，中间有空格），否则筛选和统计会看不出是径赛
- 补报的人一律**追加在名单最后**：编号 IC4-001… 是按顺序算出来的，
  插在中间会让所有人的编号错位，已经上墙的加油就指错人了（`node tools/smoke.mjs` 会检查这一条）
- 改完照旧 `node tools/build.mjs` → `node tools/smoke.mjs` → 复制上线

想核对「负责人发过来的名单」和页面是否一致（第一行写表头，逐行 `编号 姓名 项目 组别`）：

```
node tools/check-roster.mjs 名单.txt
```

它会一条条对：姓名、组别、项目（项目里有没有空格、用不用 `/` 都算一样），不一样的地方会 ❌ 标出来。

## 怎么换管理口令

`admin.js` 顶部有一行 `SECRET_HASH`。新口令的算法是
`sha256("ic4-cheer-admin|" + 新口令)`，在浏览器控制台里算出来替换那一行即可。

## 怎么更新名单 / 音乐

名单唯一真源是工作区里的 `运动会宣传/运动员名单.csv`；三首歌来自旧站 `banji-class-hub/assets/music/`
（歌名与时长从旧站 `app.js` 的 `SPORTS_BGM_TRACKS` 里读）。改完在本地工作区执行：

```
cd ic4-sports
node tools/build.mjs     # 重新生成 data.js / config.js / styles.css / assets/icons.js / sql.html
node tools/smoke.mjs     # 自检：文件齐全、不用登录、只连自己的 Supabase、名单 31 人、三首歌都在
```

再把 `index.html`、`app.js`、`data.js`、`config.js`、`cheer-api.js`、`styles.css`、
`assets/icons.js`、`admin.html`、`admin.js`、`sql.html`、`supabase/ic4-cheers.sql`
复制到 `banji-class-hub/ic4-sports/`，提交并推送。

`tools/` 里的脚本要在本地工作区（`banji-class-hub` 的旁边）运行，**只读旧站，不会改它**。

## 一个必须记住的坑：资源一定要带 `?v=`

旧站的 `banji-class-hub/sw.js` 注册的 service worker，**作用范围是整个 `/banji-class-hub/`**，
我们这一页也在里面。它的策略是：

- 页面导航 → 网络优先（部署新版，刷新就是新版）
- 站内静态资源 → **缓存优先**，它自己的注释写着「资源 URL 都带 `?v=YYYYMMDD`，
  换了版本就是换了 URL，天然不会读到旧文件」

所以 `index.html` 里每一处 `styles.css` / `app.js` / `cheer-api.js` … 都必须带 `?v=`
（`node tools/build.mjs` 会自动盖上，版本号 = 产物内容的 md5 前 8 位）。
**漏了 `?v=` 的后果**：同学浏览器一直吃旧缓存，现象是「新加的功能没出现」——
2026-10-16 就踩过：赛场原声没显示、加油墙报旧错误，全是因为资源没带版本号。

改完页面后如果同学还看到旧的，让他**关掉标签页重新打开**（或下拉刷新两次）即可。
