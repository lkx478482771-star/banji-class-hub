# 美好片刻 · 照片怎么往里放

运动会当天的照片有两种进站方式，班集站点的「IC-4 运动会」栏目会自动显示。

## 方式一：在站内直接投稿（推荐，全班都能用）

1. 打开站点 → 左侧「IC-4 运动会」→ 拉到最下面「美好片刻」。
2. 点 **上传照片**，选一张手机里的照片。
3. 浏览器会自动把它压到 64 KB 以内的 JPEG（原图不会上传），填一句说明（可留空），点 **提交投稿**。
4. 这时候照片还是「待审核」，只有管理员和班委能看到。
5. 管理员 / 班长 / 团支书 / 宣传委员 / 老师点 **审核投稿**，在列表里点 **通过**（收录）或 **驳回**（删掉）。

> 为什么只能传小图：班级共享库（MantleDB 免费版）一条记录最多 64 KB，所以照片必须在浏览器里先压缩。
> 一张 41 KB 的照片大约相当于长边 800–1000px，手机上看着够用。

## 方式二：放进仓库（画质更好，需要会 git）

照片放在本目录里，站点的「美好片刻」也会显示，而且不受 64 KB 限制。

1. **传照片**：把照片拷进 `assets/moments/`（就是本目录）。
   - 建议单张控制在 300KB 以内、长边 1600px，文件名用英文或拼音，例如 `qipao-01.jpg`。
2. **登记**：打开同目录的 `manifest.json`，在 `photos` 数组里按下面的格式加一行。

```json
{
  "updated": "2026-10-18",
  "photos": [
    { "file": "qipao-01.jpg", "title": "女子 100 米起跑" },
    { "file": "jieli-02.jpg", "title": "4×100 米接力交接", "date": "2026.10.18 上午" }
  ]
}
```

3. **提交上线**：提交并推送到 GitHub，等 1–2 分钟 GitHub Pages 自动更新。

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `file` | 是 | 文件名，要和本目录里的实际文件名完全一致（区分大小写） |
| `title` | 否 | 显示在图下面的标题，缺省是「美好片刻」 |
| `date` | 否 | 显示在图下面的小字，缺省是「2026.10.18 · 安徽大学 龙河校区」 |

## 注意

- 两种方式可以混用：站内投稿的显示为「XXX 投稿」，仓库里的显示为登记的标题。
- 一张都没有时，页面显示 8 张占位卡（开幕式 / 起跑 / 冲线 / 接力 / 跳跃 / 加油瞬间 / 颁奖 / 班级合影），这是正常的。
- 这个目录在 `assets/` 的子目录里，不参与仓库的首屏体积门禁（门禁只统计 `assets/` 的直接子项）。
- 共享库里照片大概还能放 80 张左右（命名空间上限 100 条，已用 12 条）。
- 上传前请确认照片里同学的肖像使用已经打过招呼，避免不必要的麻烦。
